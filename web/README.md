# 插件内的Velum独立调色网页

在上一层插件目录双击`一键启动.bat`。无需启动ComfyUI；默认本机8899端口，已占用时自动换端口。关闭启动窗口可停止网页服务。

本网页复用上一层`isolated_client.py` → `worker.py` → `_velum410`，不依赖任何研发目录，也不导入另一份Velum核心。布局、单图/六格/AB、图层混合、分辨率档位与下载保持原有功能。

「去色带区域算法」默认梯度能量，可选DoG引导滤波、原始DoG，与Comfy节点使用同一参数。默认720p沿用旧网页；选择「原图」才以原尺寸处理。GPU冷启动、8位sRGB输出及进程隔离说明见上一级README。

仅默认监听127.0.0.1；若确需可信局域网使用，可运行`python web/server.py --host 0.0.0.0`。本应用是共享内存工作台，不是多用户隔离服务，不应直接公开到公网。

`X-Audit`中记录版本、真实后端、worker PID、算法耗时和RPC耗时。参考图及临时计算数据仅用于当前请求/缓存；快速JPEG预览不覆盖最终PNG下载。

测试已覆盖独立HTTP上传出图和三种区域算法，且确认关闭ComfyUI后网页仍正常运行。来源与文件校验见仓库中的`ENGINE_MANIFEST.json`。
